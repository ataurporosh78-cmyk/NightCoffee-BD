# NightCoffee BD

A Jetpack Compose & Material 3 Android application for discovering late-night coffee shops across Dhaka, Bangladesh.

## Features
- Dark espresso theme designed for comfortable nighttime browsing
- Real-time **Open Now** status supporting both 12-hour and 24-hour schedules, including past-midnight closing times
- Search by shop name, neighborhood area, or popular menu items
- Filter by **Open Now**, **Family Friendly**, **Favorites**, and Dhaka areas
- Shop details with Google Maps directions, one-tap calling, sharing, and Cloud Firestore community reviews
- Community cafe submission via **+ Add Shop**
